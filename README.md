# Ifrah Abid – Personal Portfolio

A responsive personal portfolio website built with React and Vite to showcase my skills, education, and projects.

## 🌐 Live Demo

https://ifrah-react-portfolio-rose.vercel.app/

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3

## ✨ Features

- Responsive design for desktop and mobile
- Modern dark-themed interface
- Personal profile section
- About section
- Skills section
- Education section
- Projects section
- Contact section
- Responsive navigation
- Profile photo

## 📂 Project Structure

The project uses reusable React components:

- Navbar
- Home
- About
- Skills
- Education
- Projects
- Contact
- Footer
